Audit report and checklist

Test-method guide

  • Keyboard only: unplug the mouse; check Tab order, visible focus, traps, Esc, Enter and Space.
  • Screen readers: NVDA with Firefox or Chrome, VoiceOver with Safari, TalkBack on Android.
  • Zoom: 200% browser zoom and 320px width; check clipping and horizontal scroll.
  • Contrast: a color contrast analyzer, plus browser dev-tools color pickers.
  • Automated: axe DevTools, Lighthouse, WAVE. These detect only a portion of WCAG issues, so manual testing is required.
